# Brau Mono English Keyboard

Standalone Android English-only keyboard (IME), inspired by the supplied Brau Mono reference.

## Design
- Charcoal background
- Top and bottom letter rows: neon green
- Middle letter row: alternating yellow and white
- No key boxes, borders, or filled keycaps
- Monospace typography
- Thin neon-green top and bottom rules

## Features
- English QWERTY
- Shift, backspace, space, enter
- Numbers/symbols toggle
- Android system keyboard input service

## Build
1. Open this folder in Android Studio.
2. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
3. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Enable the keyboard in Android Settings > System > Languages & input > On-screen keyboard.
5. Select “Brau Mono English Keyboard”.

This source project is provided; a compiled APK is not included because Android SDK/Gradle build tooling is not available in this chat runtime.
